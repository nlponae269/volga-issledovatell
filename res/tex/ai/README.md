# Текстуры, сгенерированные в Higgsfield (по фото автора)

## dom13_facade_tile.jpg — фасад дома 13 (ул. Героев Тулы)
- Бесшовная по X и Y, 1000×904 px. Один тайл = **2 этажа × 1 пара окон** (широкое 3-створчатое + узкое 2-створчатое), кондиционер внизу.
- Размер тайла в мире: **6.2 м × 5.6 м** (этаж 2.8 м).
- Roblox: `Texture` на грань стены, `StudsPerTileU = 22.1`, `StudsPerTileV = 20.0` (при 1 м = 3.57 studs).
  Начало тайла по вертикали — верх цоколя (OffsetStudsV подогнать так, чтобы окна 1-го этажа были на высоте ~0.85 м над полом этажа).
- Three.js: `repeat = (длина_стены/6.2, высота/5.6)`, `wrapS/T = RepeatWrapping`.
- `dom13_facade_raw.png` — исходник 1024×1024 без обрезки.
- Превью повторения: `docs/worlds/dom13_facade_preview.jpg`.

## dom13_facade_atlas.jpg — 4 варианта окон (используется в игре)
- 4000×1808 px = 4 тайла по ширине × 2 по высоте (4 этажа), разные шторы/лампа/форточка/газета/старые рамы, кондиционеры в разных местах.
- Размер в мире: **24.8 м × 11.2 м**. Roblox: `StudsPerTileU = 88.5`, `StudsPerTileV = 40.0`.
- Исходники вариантов: `dom13_facade_raw_v1..3.png`. Превью: `docs/worlds/dom13_facade_atlas_preview.jpg`.

## panel_atlas.jpg — панельки (3 цвета секций)

- Размер в мире: **36 м × 11.2 м** (секция 12 м). Низ тайла = верх цоколя (1.6 м). Roblox: `StudsPerTileU = 128.5`, `StudsPerTileV = 40.0`.
- Исходники: `panel_raw_white/beige/lilac.png`.

## podezd_wall_1.jpg, podezd_wall_2.jpg — стены подъезда
- 1024×1024, бесшовные по X. Один тайл = **2.8 × 2.8 м** (пол → потолок). Граница краски на 1.55 м от пола.
- Бирюзовая масляная краска + побелка, надписи «Цой жив», «КИНО», «Катя + Дима», «Спартак», «ЛЁХА», «выхода нет», снежинки.
- Roblox: `StudsPerTileU = StudsPerTileV = 10.0`, начало тайла — уровень пола этажа.
