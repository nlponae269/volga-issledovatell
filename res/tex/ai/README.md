# Текстуры, сгенерированные в Higgsfield (по фото автора)

## dom13_facade_tile.jpg — фасад дома 13 (ул. Героев Тулы)
- Бесшовная по X и Y, 1000×904 px. Один тайл = **2 этажа × 1 пара окон** (широкое 3-створчатое + узкое 2-створчатое), кондиционер внизу.
- Размер тайла в мире: **6.2 м × 5.6 м** (этаж 2.8 м).
- Roblox: `Texture` на грань стены, `StudsPerTileU = 22.1`, `StudsPerTileV = 20.0` (при 1 м = 3.57 studs).
  Начало тайла по вертикали — верх цоколя (OffsetStudsV подогнать так, чтобы окна 1-го этажа были на высоте ~0.85 м над полом этажа).
- Three.js: `repeat = (длина_стены/6.2, высота/5.6)`, `wrapS/T = RepeatWrapping`.
- `dom13_facade_raw.png` — исходник 1024×1024 без обрезки.
- Превью повторения: `docs/worlds/dom13_facade_preview.jpg`.
