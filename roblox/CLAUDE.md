## 1. Что за игра (коротко)

**«Тишина»** — атмосферный «сон» от первого лица про детство в Волгограде (пос. ГЭС, 415-й микрорайон).
Нет монстров и скримеров — жутко от пустоты. Игрок ходит по мирам-воспоминаниям, собирает записки и
**16 ключей от ворот**. Все ключи → бабушкины ворота на даче открываются → игрок возвращается во двор,
поднимается домой в **кв. 47**, ложится спать → «минута пошла дальше, мама пришла». Конец.

### Главные миры (на них весь упор, делать максимально реалистично)
- **ДВОРЫ** — двор дома **ул. Героев Тулы, 13**. **Ноябрь, 14:50**, пасмурно, дождь только что кончился.
  Светлая грязь с лужами-зеркалами, кирпичные и панельные девятиэтажки, тополя и берёзы, голуби, старые машины,
  бетонный лом. Часы в HUD: `ноябрь · 14:50:SS` — минута никогда не меняется. 12 записок, ключ на площадке с самой яркой крышей.
  Смысл: ты пришёл из школы, ключа нет, домофон молчит — застрял в одной минуте детства.
- **ПОДЪЕЗД** — **новогодняя ночь**, бесконечная лестница панельки: 4 квартиры на этаже, лифт, лестница.
  Масляная краска + побелка, надписи, мишура, за дверями празднуют. В лифте вместо кнопок табло: вводишь любой этаж,
  можно до **2147483647**, дальше переполнение int32 → глитч. Кв. 47 на 3-м этаже ведёт в Квартиру.
  Смысл: дом, куда хочется попасть, но он бесконечный.
- **КВАРТИРА 47** — дома никого, записка от мамы, суп на плите, в окне настоящий двор. Кровать: заснуть → другой мир / финал.

## 2. Шаг 1 — загрузить текстуры в Roblox (автору почти ничего не делать)

**Вариант А (рекомендую, полностью автоматически):**
1. Попроси автора один раз создать ключ: **create.roblox.com → Dashboard → Credentials → Create API Key**,
   доступ **Assets API: read + write**, IP `0.0.0.0/0`. И сказать свой **userId** (число в адресе профиля).
2. Запусти в терминале из папки пакета:
   `pip install requests && ROBLOX_API_KEY=<ключ> ROBLOX_USER_ID=<id> python3 upload_roblox.py`
3. Получишь `ids.json` — имя файла → asset id. Дальше всё ставь по этим id.
   > Скрипт написан по документации Open Cloud Assets API, но в первой сессии не запускался (там нет ключа). Если ответ API другой — поправь по ошибке.

**Вариант Б (вручную, но один раз):** Studio → **View → Asset Manager → Bulk Import** → выбрать все файлы из `textures/`.
После импорта попроси автора скопировать ID (ПКМ → Copy Asset ID) или читай их из Asset Manager.

### Если текстура не видна
Через Open Cloud загружается **Decal**. В `Texture.Texture` / `SurfaceAppearance.ColorMap` нужен ID **картинки**.
Если не грузится — получи ID картинки через `InsertService:LoadAsset(decalId)`: внутри будет `Decal`,
бери его `.Texture` (это `rbxassetid://<imageId>`), сохрани в таблицу и используй его.

## 5. Порядок работы (делай так)
1. Загрузить текстуры (раздел 2) → `ids.json` / таблица `TEX = { pod_floor = "rbxassetid://..." , ... }` в ModuleScript `ReplicatedStorage/Shared/Tex`.
2. MaterialService: MaterialVariant для земли (Mud), асфальта, тротуара, бетона, плитки и крошки подъезда.
3. Свет/атмосфера из раздела 3.
4. **Подъезд**: стены (4 варианта по этажам), пол, ступени, потолок, двери (3 вида), лифт, почтовые ящики, лампочки.
5. **Дворы**: фасады дома 13 и панелек, цоколь, порталы и синие двери подъездов, земля/асфальт/тротуар, бетон, кора деревьев, контейнеры, заборы, люки.
6. Сравни скрины с `screenshots/new_*.jpg` (так выглядит оригинал) и `screenshots/<мир>.jpg`, выпиши 5 главных отличий, исправь.
7. Отчёт автору: что сделано, скрин, что проверено.
