# Тишина Cloud — свой облачный гейминг

Игра запускается **на сервере** (Chromium), в браузер телефона/ПК идёт только картинка (JPEG-кадры по WebSocket),
касания и клавиши уходят обратно в игру. Ничего ставить на телефон не нужно.

## Бесплатно, без карты: GitHub Codespaces
1. github.com/nlponae269/volga-issledovatell → зелёная кнопка **Code** → вкладка **Codespaces** →
   «…» → **New with options** → ветка `claude/procedural-world-generation-2uyvij` → **Create codespace**.
2. Первый запуск ставит Chromium (~3–5 мин). Потом сервер стартует сам.
3. Внизу вкладка **Ports** → порт 8080 «Тишина Cloud» → ссылка (глобус). Эту ссылку открываешь на телефоне.
   Если пишет «приватный» — ПКМ по порту → Port Visibility → **Public**.
4. Codespace сам засыпает через 30 мин без активности. Включить снова: github.com/codespaces → твой codespace → Open.

Бесплатно GitHub даёт 120 «ядро-часов» в месяц: на машине с 4 ядрами это ~30 часов игры.
Чтобы было ~60 часов — в `.devcontainer/devcontainer.json` поставь `"cpus": 2` (кадров будет меньше).

## На любом сервере
```
cd cloud && npm install && npx playwright install --with-deps chromium && node server.js
```
Переменные: `PORT` (8080), `W`/`H` (960×540), `Q` — качество JPEG (55), `KEY` — пароль (тогда ссылка `/?k=пароль`),
`GPU=1` — если на сервере есть видеокарта (например, Lightning AI).

## Ограничения (честно)
- Без видеокарты картинку рисует процессор: меню ~35 к/с, тяжёлые 3D-миры (Дворы) — несколько кадров в секунду.
  Лёгкие миры (Настройки, ТРАМ𒀱Й, Водитель) идут лучше. С GPU — плавно.
- Звук идёт со стрима (PCM 24 кГц, ~0.1–0.2 с задержки). На телефоне надо один раз тапнуть по экрану, чтобы браузер разрешил звук.
- Все, кто открыл ссылку, видят и управляют одной и той же игрой.
